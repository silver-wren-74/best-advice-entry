Entry for the make.fun competition **The Best Advice I Ever Got**: one sentence,
up to 200 characters, about the best advice I ever received.

`main.ts` writes the sentence to `/output/entry.txt`:

> The night I failed my driving test, my grandfather slid his keys across the
> table and said: never borrow trouble from tomorrow, because today already
> charges enough interest.

Run it with Node 22.18+:

```sh
node main.ts
```
